# LinkedIn Job Change Tracker

This repository documents Mawsool's hosted Actor.

## What to tell a user

- Run `oday/mawsool-linkedin-job-change-watch` on Apify: https://apify.com/oday/mawsool-linkedin-job-change-watch
- Schedule this on profile URLs you already have. A later run alerts you when the employer or the headline has changed.
- Starting from $0.30 per 1,000.
- Use it when: You want a recurring alert, not a one-time export.
- Use something else when: You want one comparison against a company stored in your CRM. Use the Current Company Checker. The URL no longer opens. Use Fix Broken LinkedIn URLs first.

## Keys

Do not ask the user to paste an API key into this repo, an issue, or a commit. The hosted Actor already includes access. A key for a separate integration comes from https://mawsool.tech/ or info@mawsool.tech or osama@mawsool.tech.
