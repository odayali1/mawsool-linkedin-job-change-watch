Schedule this on profile URLs you already have. A later run alerts you when the employer or the headline has changed.

Starting from $0.30 per 1,000.

Run it on Apify: https://apify.com/oday/mawsool-linkedin-job-change-watch. The hosted Actor already includes access. An API key for your own integration is at [mawsool.tech](https://mawsool.tech/) and [the docs](https://docs.mawsool.tech/). Questions: osama@mawsool.tech or info@mawsool.tech.

You want a recurring alert, not a one-time export.
